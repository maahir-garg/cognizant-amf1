### [04:30 - 05:30] The AI Trust Layer & Zero-Hallucination Architecture
- **Speaker**:  
  > "Why is this solution trusted? In ESG, a hallucinated number is a regulatory and reputational catastrophe. We engineered a three-tier Trust Layer:  
  > 1. **Grounded Fact Base**: Only facts extracted from official AMF1 reports are passed to the model.  
  > 2. **Post-Generation Numeric Guardrail**: Every digit, float, and percentage in AI copy is parsed via regex. If any number fails to match a cited fact or verified conversion formula, the output is rejected.  
  > 3. **Demo Resilience**: We built an offline cache in `data/ai-cache/`. If event Wi-Fi collapses at Marina Bay, the entire prototype continues to execute offline with zero latency."
